## 做法与规矩

- 一律用 **BBDown 免登录下载原片音轨**（`--audio-only`），再用 ffmpeg 截段：
  先把音轨降到 8 kHz 单声道算 RMS，取能量最高的一段（避开片头片尾），
  这样音乐类的段落基本都落在唱段/鼓乐上，不用手填时间码。
- **每段只留 12 秒**：先按 30–38 秒挑好段落，再在同一段里挑能量最高的 12 秒二次收短，
  避免整首/整段落进仓库。站点要上 GitHub Pages，体积比完整性重要。
- 每次截完统一 `loudnorm I=-16 TP=-1.5`、`afade` 0.22 秒淡入 / 0.38 秒淡出，
  输出 44.1 kHz 立体声 96 kbps MP3（每段约 142 KB），并写入 ID3 标题与来源说明。
- `assets/audio/data/{key}.js` 只有六段主选段需要，是同一段 mp3 的 base64，
  **只给双击打开（`file://`）时用**；改音频后跑 `python tools/make-audio-data.py` 重新生成。
  其余 17 段由数据库页面用 `<audio>` 直接播放，不走 Web Audio，也不需要数据脚本。
- 富川织锦一栏用的是江华瑶族织锦影像（`brocade.mp3`）与瑶族织锦纪录片（`brocade2/3/4.mp3`），
  不冒充富川本地录音；页面文案写「瑶族织锦现场声」，不写成「富川织锦歌曲」。
- 版权归原视频作者与相关机构所有，仅作非商业性的课程展示与声音可视化实验；
  若后续需要正式公开传播，请替换为已获授权的录音，或在页面标注更完整的授权信息。
