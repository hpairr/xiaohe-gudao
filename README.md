# 潇贺古道有声文化数据库 · 多语种可视化界面

视觉传达毕业设计作品。以声音与影像为线索的潇贺古道文化数据库：文化档案 / 声音数据库 / 古道图志 / 数据来源。

**线上地址：<https://hpairr.github.io/xiaohe-gudao/>**

## 直接打开

双击 `index.html` 即可（Chrome / Edge 均可）。字体与图集随目录携带，不依赖外部 CDN、不需要本地服务器。

站点分两页（2026-10-22 起）：

- **`index.html`** —— 站点首页，滚动剧场：古道影像收缩去色 → 沿线跑马灯 + 物理丝缕 → 序章「170 公里」→ 六章 → 六章索引 → 尾声。
- **`database.html`** —— 数据库站（单页应用）：文化档案 / 声音数据库 / 古道图志 / 关于与来源 + 七语界面；空 hash 直接落到 `#/archive`，顶栏「首页」回 `index.html`。

> 2026-10-23：首页六章为 **女书 / 蝴蝶歌 / 长鼓舞 / 富川风雨桥 / 盘王大歌 / 瑶族织锦**；古道退回序章与图志，炸龙与古道旧页归档，保留查阅。

**统一外框**：女书「八角连弧纹」—— 圆心 (80,80)、顶点半径 64、8 顶点跳 3 位相连、
每条边沿垂直弦方向内压 0.25×弦长 → 边中点半径 54.06（凹深 10）。
这套几何与主页底部的装饰带、每条主题条目的纹章是同一份。

设计依据与逐条出处见 `docs/06-技术方案/06-主页纹样与主题页设计说明.md`；

## 子页面改版（2026-10）：从“白卡后台”回到“可翻阅的出版物”

主站原来的「文化档案 / 详情 / 声音 / 图志 / 关于 / 城市」是白底圆角卡片 + 蓝色表头的后台样式，
和首页的宣纸—朱砂—巨字不是一套语言。这一轮把子页面统一成**编辑型档案界面**：

- **没有白卡、没有圆角、没有投影**：用 1px 硬边界、上边线、目录号组织内容。
- **标题重新成为版面主体**：`文化档案 / 声音数据库 / 古道图志 / 关于与数据来源` 用 50–104px 衬线巨字。
- **详情页改成博物馆对象页**：全幅图像 + 右侧元数据栏 + “它是什么 / 关键事实 / 出处 / 继续沿路”。
- **声音页改成听音目录**：编号、标题、说明、平台、播放按钮在同一行；不再是 26 张视频卡片。
- **图志改成目录**：地图、图例、节点、城市四层，地图是索引，不是插图。
- **专题页共用 `themes/editorial.css`**：去掉专题页里的白卡、蓝色表头和圆角胶囊。

## 视频策略（重要）

26 条视频分两类：

| 类型 | 数量 | 播放方式 |
| --- | --- | --- |
| 本地整理版 | 19 条（≈ 573 MB，在 `video/`） | 原生 `<video>` 播放本地文件 |
| 平台外链 | 7 条（原片过大，已移出站点） | 内嵌 B 站播放器 |

换成自己的剪辑版：**只改 `index.html` 里的 `VIDEO_URLS` 表**（在页面源码里搜索「视频外链配置」）。

- 填 B 站视频页地址 → 内嵌官方播放器（支持 `?p=3` 分 P）
- 填 `.mp4` 直链 → 原生播放器
- 填其它网页地址 → 显示「前往平台观看」按钮
- 留空 `''` → 用本地 `video/{id}.mp4`；**本地文件缺失时自动回退到该条目的来源平台链接**（这就是线上能正常播放的原因）

逐条对照表：`docs/视频外链对照表.md`。移出的 7 个原片在站点目录之外：
`../_离线归档-大视频未上传/`（未删除，可随时搬回 `video/`）。

**线上地址：<https://hpairr.github.io/xiaohe-gudao/>**

2. 本目录已经 `git init` 并完成首次提交，只需添加远程并推送（或直接用 GitHub Desktop 发布）
3. 仓库 **Settings → Pages → Deploy from a branch → main → /(root)**，等 1–3 分钟
4. 换地址后重跑 `node tools/set-site-url.mjs --user 用户名 --repo 仓库名`；
   上线前跑 `node tools/check-site.mjs` 自查

`video/`、`hero/`、`tests/`、字体源 TTF 与设计过程素材不进仓库（`.gitignore` 已排除），
线上站点约 23 MB，远低于 Pages 的 1 GB 限制。
