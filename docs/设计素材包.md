## 一、项目定位与设计理念

**一句话定位**:面向公众与研学群体的潇贺古道有声文化遗产数字平台,内容主体为**潇贺古道**(秦建「新道」)——"让古道的声音被听见、被看见、被听懂"。

- **内容域**:平台整体按「潇贺古道」定位——北起湖南道县潇水、南抵广西贺州贺江的秦建「新道」沿线:通道关隘、遗迹古村、瑶族非遗(蝴蝶歌/长鼓舞/瑶族服饰)、女书习俗与历史人物,兼及沿线声音档案。
- **设计关键词**:水韵(波纹/流动)、声纹(波形/频谱)、墨韵(水墨/古籍)、方言(地域/多元)。
- **视觉隐喻**:「声波如流水」——把音频波形与运河水流形态同构,贯穿 logo、导航动效、数据可视化。
- **参考范式**:
  - 信息架构参照「数字中国·大运河」(shuziyunhe.com)+ 中国网大运河频道(按沿线城市组织);
  - 有声内容详情页参照 ihchina.cn 音频频道(曲目+演奏者+流派+相关推荐);
  - 数据叙事参照数字敦煌(采集精度等专业指标可视化);
  - 多语种参照故宫博物院(7 语种平铺切换)+ 数字敦煌(中英双语)。

│   ├── 声音地图(GIS:沿线城市方言点/音频点位)

## 四、多语种界面方案(遵循 W3C 国际化规范)

### 4.1 语言切换器

- **语种范围建议 6 种**:简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français(可扩展);
- **形式**:顶部右上角**平铺文字链接**(<6 种不推荐下拉),写目标语言原生写法:`中文 | 繁體 | English | 日本語 | 한국어 | Français`,外层 `<span lang="…">`;
- **禁用国旗图标**(W3C 明确反模式:bittersmann.de/articles/no-flags);
- 交互:JS 切换 `data-i18n` 文案 + `localStorage` 记忆选择;服务端按 `Accept-Language` 内容协商为补充;
- 参照:故宫博物院 dpm.org.cn 顶部 7 语种平铺。

### 4.2 技术底座清单

| 项 | 要求 |
|---|---|
| 编码 | 全站 UTF-8,`<meta charset="utf-8">` |
| 语言元数据 | `<html lang="zh-CN">`,切换后更新;每段外文标 `<span lang>` |
| 方向 | 默认 LTR;为未来阿拉伯语预留 `dir="rtl"` 支持,CSS 一律用逻辑属性(`margin-inline-start`、`inset-inline-end`),不写死 left/right |
| 动态文本 | 用户生成内容用 `<bdi>` 或 `dir="auto"` 包裹 |
| 文字增长 | 按钮/标签预留 30–50% 文案增长空间(德/俄文更长);不固定截断 |
| 数字/日期 | 用 `Intl.NumberFormat` / `Intl.DateTimeFormat` 本地化;语种标签长度自适应 |

### 4.3 文案规则

- 语种名用原生写法+括号注释:`한국어(韩语)`;
- 方言条目三语并列:方言名(原生)+ 普通话转写 + 英文译名;
- 音标用 IPA 统一标注(参照中国语言资源有声数据库/语保工程规范)。

## 五、有声内容可视化方案

### 5.1 声音地图(核心可视化)

- 技术:ECharts map(echarts.apache.org,Apache 2.0)+ 阿里 DataV GeoJSON(`geo.datav.aliyun.com/areas_v3/bound/100000_full.json`,实测可用);
- 呈现:长江以南运河沿线城市点位,点大小=音频数量,点击弹卡片试听;`visualMap` 用天水碧→群青连续色带分级;
- 图层叠加(参照浙江大运河文化数智云平台「水利-生态-文化多维图层」):方言区图层 / 非遗类型图层 / 历史节点图层可开关。

### 5.2 音频波形与频谱

- 播放器:wavesurfer.js v7(wavesurfer.xyz,BSD-3 开源)——波形+播放进度着色;Regions 插件做逐句/逐段标注(方言例句分段);Spectrogram 插件显示声纹语图;Timeline 时间刻度;
- 自绘方案(备选):MDN Web Audio API `AnalyserNode` 教程(oscilloscope + frequency bars);
- 视觉规范:波形主色远天蓝,播放进度天水碧,当前句高亮朱砂红。

### 5.3 数据看板(首页大屏)

- 指标:收录声音条数、语种/方言数、覆盖城市数、传承人访谈数、采集进度%;
- 图表:方言分布环图、年代堆积柱、城市横向条形;数字用「数字+印章红强调」样式;
- 参照:数字敦煌以采集精度/壁画面积等专业指标做叙事,建立数据信任。

### 5.4 其他可视化

- 古地图对照:古籍舆图(扫描件)与 ECharts 现代地图左右联动;
- 词云:民歌高频词;知识图谱:主题-人物-地点关联(参照「数字中国·大运河」知识图谱)。

## 八、答辩要点(3 句话)

1. **真实性**:平台内容与功能对标里运河文化资源专题库(淮安,2025)、中国语言资源有声数据库等真实项目,信息架构采用「沿线城市 × 声音类型」双维组织;
2. **原创性**:「声波如流水」视觉隐喻 + 中国传统色体系(群青/天水碧/朱砂)+ 三语并列转写,多语种方案完全遵循 W3C 国际化规范;
3. **可行性**:全部技术选型免费开源(ECharts + wavesurfer.js + 思源字体 + DataV GeoJSON),可离线单文件原型演示(见 index.html)。
