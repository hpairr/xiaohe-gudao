# 首页自动配乐（六章随滚动切换）

> 首页滚到哪一章，就起哪一章的声音；换章先淡出旧的、再淡入新的；滚出六章（进入索引/尾声）就停。
> 代码全在 `assets/audio-player.js` 里，`index.html` 不需要额外挂东西。

## 怎么用

1. 打开首页，顶栏右侧会出现「开启声音」——浏览器规定：没有点击/按键，AudioContext 不能出声。
2. 点一下（或页面上任意一次点击/按键），当前章的声音淡入。
3. 往下滚，换章时旧声音 0.9 s 淡出、新声音约 1.1 s 淡入，两段会有短暂交叠，不是硬切。
4. 滚过 `#chapter-stage`（六章舞台）进入「六章索引」或「尾声」，声音淡出并停；
   滚回章内会接着响。
5. 再点顶栏按钮 = 静音；选择记在 `localStorage['xiaohe-sound']`，下次打开保持关着。

## 参数（`assets/audio-player.js` 顶部）

| 常量 | 现在 | 作用 |
| --- | --- | --- |
| `AUTOPLAY` | `true` | 首页是否随滚动自动起声音；关掉就退回“必须点播放键” |
| `AUTO_GAIN` | `0.62` | 自动播放的目标音量（手动点播放仍是 0.9） |
| `SOUND_KEY` | `xiaohe-sound` | 总开关的本地记忆键 |
| `MIN_STAGE_VISIBLE`（内联在 `stageInView`） | 0.2 屏 | 舞台可见度低于这个值就算“出章”，停声 |
| 淡出 | 0.9 s | `pause()` 里的 `linearRampToValueAtTime` |
| 淡入 | 0.35–1.15 s | `play()` 里按剩余时长取 |

## 音源与文件

- 六段 35 秒选段：`assets/audio/{nushu,butterfly,drum,bridge,panwang,brocade}.mp3`（561 KB）
- 播放时优先 `fetch` 这个 mp3 再 `decodeAudioData`；只有 fetch 不可用（`file://` 预览、
  或某些本地服务器对媒体请求回空 body）才退回 `assets/audio/data/<key>.js` 的 base64。
  这样可以少下载 25%，也不用把 748 KB 的 JS 当脚本解析。
- 曲目信息（标题、出处、B 站链接）在 `assets/audio-player.js` 的 `META` 里
- 六章的播放器由 `assets/theme-stage.js` 生成（`data-audio-player data-key=...`），
  每章左下角那一套播放/波形/时间仍然是独立的，可以单独暂停
- 进入一章后会在后台预取下一章的 mp3（`warmNextChapter`），换章不用干等；
  `navigator.connection.saveData` 为真时跳过预取

## 边界与注意

- 手机静音键、iOS 低电量模式会接管音频，页面里的开关看起来“开了”也可能没声，属系统行为。
- 切到后台（`visibilitychange`）会暂停，回到前台且未静音时自动继续。
- 专题页**不会**自动播放：`runAuto()` 只在存在 `#chapter-stage` 的页面生效，
  专题页的播放器保持“点了才响”。
- 快速连续滚过几章时，用 `player.token` 作废还在解码的那一次，避免两首同时响。
- 音源版权与出处见各段 `META.credit` 与页面脚注；公开传播前按原计划取得授权。
