> 站点：**潇贺古道有声文化数据库**
> 线上地址：<https://hpairr.github.io/xiaohe-gudao/>
> 仓库：`hpairr/xiaohe-gudao`（Public）
> 站点根目录：本目录 `xiaohe-gudao-db/`

## 0. 现在的状态

- 首页、数据库（文化档案 / 声音 / 图志 / 关于）、8 个专题页、404 页都已完成。
- 字体已换成 `assets/fonts/site/` 下的 WOFF2 全站子集：手机首次打开不再下载 50 MB 字体。
- 13 个页面的 `canonical`、`og:*`、`sitemap.xml`、`robots.txt` 已指向真实地址。
- `.gitignore` 已排除本地视频、hero 试验场、测试件、字体源文件和设计过程素材。
  预计入库约 **23 MB / 120 个文件**。

你只差三步：**建仓库 → 推送 → 打开 Pages**。

## 1. 建仓库（网页，约 2 分钟）

1. 打开 <https://github.com/new>
2. **Repository name** 填 `xiaohe-gudao`
3. 可见性选 **Public**
4. **不要**勾 “Add a README file”“Add .gitignore”“Choose a license”
5. 点 **Create repository**

## 2. 推送（二选一）

### A. GitHub Desktop（不熟悉命令行时推荐）

1. 安装并登录 [GitHub Desktop](https://desktop.github.com/)
2. **File → Add local repository…**，选择本目录 `xiaohe-gudao-db`
3. 左下角填写提交信息，点 **Commit to main**
4. 点顶部 **Publish repository**，取消勾选 “Keep this code private”，发布到 `hpairr/xiaohe-gudao`

### B. 命令行（本机已装 Git）

在**本目录**执行：

```bash
git remote add origin https://github.com/hpairr/xiaohe-gudao.git
git push -u origin main
```

第一次推送会要求登录。密码处填 **Personal Access Token**（不是账号密码）：
GitHub → 头像 → Settings → Developer settings → Personal access tokens →
Tokens (classic) → Generate new token，勾选 `repo`，复制后粘贴到密码提示处。

## 3. 打开 Pages

1. 仓库页 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，目录选 **`/(root)`**，点 **Save**
4. 等 1–3 分钟，同一页顶部出现网址：
   **<https://hpairr.github.io/xiaohe-gudao/>**

第一次打开如果 404，先等 2 分钟再刷新；仍是 404 就检查 Pages 是否显示 “Your site is live at …”。

## 4. 以后改了仓库名怎么办

一条命令改完所有 `canonical`、`og:url`、`og:image`、`sitemap`、`robots`、404 页链接：

```bash
node tools/set-site-url.mjs --user hpairr --repo 新仓库名
node tools/check-site.mjs
git add . && git commit -m "更新站点地址" && git push
```

`check-site.mjs` 会检查每页的本地引用是否存在、标题/描述/canonical 是否齐全、
有没有残留占位符；输出“全部通过”再推送。

## 6. 让搜索引擎收录

| 引擎 | 做法 |
| --- | --- |
| **Google** | <https://search.google.com/search-console> → 添加资源 → 网址前缀填 `https://hpairr.github.io/xiaohe-gudao/` → HTML 标记验证（把给的 `<meta name="google-site-verification" …>` 贴进 `index.html` 的 `<head>`）→ 提交 `sitemap.xml` |
| **Bing** | <https://www.bing.com/webmasters> 同上，可直接从 Google Search Console 导入 |
| **百度** | 基本不收录 `*.github.io`。要进百度只能绑自定义域名，或另部署到 Cloudflare Pages / Vercel |

`sitemap.xml` 已列首页、数据库与 8 个专题页，`robots.txt` 已指向它。
收录通常要几天到几周，不要反复重复提交。

### 本地预览（改了页面先看）

```bash
node tools/preview.mjs        # 默认 http://127.0.0.1:8080/
```

这个零依赖服务器支持 HTTP Range，教学片可以拖动、点动作跳转。
**不要用 `python -m http.server` 预览带视频的页面**：它不支持 Range，
视频无法 seek，点动作只会从头播。

## 8. 硬限制与注意

| 限制 | 数字 | 对本项目 |
| --- | --- | --- |
| 单文件 | >100 MiB 拒绝推送 | 已排除 `video/` 与字体 TTF |
| 仓库 / Pages 总量 | 建议 <1 GB / 站点 ≤1 GB | 入库约 23 MB |
| 带宽 | 软限 100 GB/月 | 毕设展示足够 |
| Git LFS | Pages 不支持 | 不要用 LFS 放视频 |
| 发布目录 | 仓库根目录或 `/docs` | 入口 `index.html` 已在根目录 |

- 目录在 OneDrive 里，`.git` 同步时偶发文件锁；如遇异常，把仓库克隆到 `D:\repos\` 再操作。
- 不要把 `video/` 加回仓库；线上播放靠 `database.html` 的 `VIDEO_URLS` 外链，
  本地文件缺失时会自动回退到来源平台。
- 专题页 `themes/04-长鼓舞.html` 的基础教学片同样走本地 `video/04-changgu-basics.mp4`
  （约 18 MB，不进仓库）。线上会显示「教学片未加载 · 在抖音观看原片」的退路；
  要让线上也能在页内播放，先把片子放到 B 站／对象存储，再把 `themes/assets/dance.js`
  顶部的 `VIDEO_SRC` 改成直链（只改这一处）。
- 8 个专题页顶部的「图版 01 · 待补」是预留的实物图位置，拿到授权图后替换即可。
