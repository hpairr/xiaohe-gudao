## 填网址的三种写法

| 你填的内容 | 页面表现 |
| --- | --- |
| `https://www.bilibili.com/video/BV1xx411c7mD/`（可带 `?p=3` 分 P） | 内嵌 B 站官方播放器 |
| `https://你的存储地址/xx.mp4` | 原生 `<video>` 播放器 |
| 其它任意网页地址 | 显示「前往平台观看」按钮 |
| 留空（空字符串） | 用本地 `video/{id}.mp4`；本地缺失时自动回到来源平台链接 |
