# 视频静帧与封面（站点不放视频，只放图）

> 站点**不放任何视频**：591 MB 原片全部留在本机 `video/`，不进仓库（2026-11-07 起长鼓舞教学片也退出了仓库）。
> 数据库里的 19 条影像记录改用 12 秒音频选段出声，完整片走 B 站外链；
> 长鼓舞教学台线上自动退成 21 张静帧，页内给抖音原片链接。

## 两处用途

| 用途 | 位置 | 数量 | 生成方式 |
| --- | --- | --- | --- |
| 长鼓舞教学台 | `themes/assets/dance-frames/01.jpg … 21.jpg` | 21 张（1280×720） | 按 `04-长鼓舞.html` 里 21 个动作的 `data-start` 逐帧截取 |
| 声音数据库封面 | `assets/img/video-covers/<id>.jpg` | 19 张（960×540） | 每条 `video/<id>.mp4` 自动挑一帧，个别手动钉死秒数 |

脚本：`tools/make_video_stills.py`（需要本机 `ffmpeg` / `ffprobe`，以及 `video/` 里的原片）

```powershell
cd xiaohe-gudao-db
python tools\make_video_stills.py dance    # 长鼓舞 21 张
python tools\make_video_stills.py covers   # 数据库 19 张
python tools\make_video_stills.py all      # 都要
```

## 长鼓舞教学台

- 主画面优先用本地 `video/04-changgu-basics.mp4`（只在本机存在），封面用静帧 01；
  点右侧动作名 → `currentTime = 动作起点`，播放；播放时读数、刻度尺跟着走。
- **线上没有这条 mp4**：加载失败 → 自动切静帧模式，同一套 21 张图、同一份列表，
  只是点动作变成换图；标题行右侧有「原片 ↗」指向抖音。两种模式共用一套交互，不弹错误提示。
- 以后要把片子放上线在页内播：把 `themes/assets/dance.js` 顶部的 `VIDEO_SRC` 填成直链，
  其余不用改（HTML 里的本地路径会被它覆盖）。
- 时间点改了就重跑 `dance`，图和页面不会对不上（脚本直接读 HTML 的 `data-start`）。
- 取帧时间是 `data-start + 1.0 s`：避开上一动作的收势，落在本动作的定式上。
- 图上文字是原片自带字幕，不是后加的。
- 本地预览要用 `node tools/preview.mjs`（支持 Range）；`python -m http.server` 不支持分段，
  视频拖不动，会误以为“跳转失效”。

## 数据库封面

- 点“播放”先出封面，**再点画面**才加载 `video/<id>.mp4`；
  线上没有原片时，`<video>` 报错会自动回退到该条目的来源平台（B 站内嵌）。
- 自动挑帧规则：在片长 10%–80% 之间试 8 个点，排除过暗/过亮，取对比度最高的一帧。
- 自动挑出来是字幕板或空镜的，写进脚本顶部的 `COVER_FIXED` 手动钉死秒数（现已钉了 so1 / so9 / so15a / so16）。

## 注意

- 静帧是从抖音/B 站下载的原片里截的，**版权仍归原作者**；页脚已有来源与“仅作教学参考”的说明，公开上线前按原计划取得授权。
- 不要用截图工具手截：手动截图会和页面时间码脱节，重跑脚本才能保持一致。
- 两张表的图片命名都由 `<id>` / 序号决定，增删视频时同步改 `COVER_IDS` 或页面里的 21 行。
