> 站点：<https://hpairr.github.io/xiaohe-gudao/>　仓库：`hpairr/xiaohe-gudao`
> 本地目录：`C:\Users\35219\OneDrive\桌面\毕设\xiaohe-gudao-db`

## 一、你（人）要做的六件事

按顺序，缺一件都可能白跑一趟。

### 1. 确认加速工具开着

打开任务栏托盘看一眼 Steam++ 是否在运行。
它现在把 `github.com` 指向本机 `127.0.0.1`，**关掉就连不上**，推送会卡在连接上。

自检（PowerShell 里跑，返回 200 就说明通）：

```powershell
curl.exe -I https://github.com
```

### 2. 把正在编辑的文件保存并关掉

最重要的一条。AI 提交的是**磁盘上已保存的版本**：

- 编辑器里没保存的改动 → 不会被传上去
- 反过来，你改到一半、保存了一半的文件 → 会被当成"这次要传的内容"传上去

尤其是 `index.html`：它现在有一大段未提交的改动（首屏"一条尺 / 西线东线"，2026-10-30 20:14）。
**改到你自己满意了，再让它传。**

### 3. 告诉它"改完了，可以传了"

顺带一句话说明改了什么，例如：

> 改完了，可以传了。这次改的是首屏路线尺、专题页进场动画。

这句话会被拿去做提交说明，将来回看历史时一眼就知道这次干了什么。

### 4. 说清楚这次**哪些要传、哪些不要**

默认规则：

| 要传 | 不要传 |
| --- | --- |
| `index.html`、`database.html`、`themes/`、`assets/`、`images/`、`docs/` | `video/`（573 MB）、`hero/`（试验场）、`tests/`、字体 TTF、`images/视觉转化素材库/` |

这些"不要传"的目录已经写进 `.gitignore`，正常情况下不会误传。
但如果你**新建了目录**，要主动说一句"这个也要传"，否则它可能被忽略规则挡住。

### 5. 如果你要改仓库名或换域名，先说

换仓库名后，所有页面的 `canonical`、分享卡片地址、`sitemap.xml` 都要跟着改。
一条命令能改完，但要放在推送之前：`node tools/set-site-url.mjs --user 用户名 --repo 新仓库名`

### 6. 决定：只提交，还是直接推上去

- **只提交**：改动记进本地历史，网站上不变，你可以先看
- **直接推**：约 1–2 分钟后线上就是新版

说清楚要哪种，不然默认会直接推。

## 二、AI 会做的检查（你不用操作，但可以盯着）

1. **分清改动归属**：`git status` 里哪些是你改的、哪些是上次留的，分得清才敢提交
2. **站点自检**：`node tools/check-site.mjs`，要求输出"✓ 全部通过"（11 页、0 问题）
3. **本地预览**：`node tools/preview.mjs` 起在 `http://127.0.0.1:8080/`，改完页面先看效果
4. **体积检查**：单文件不能超 100 MB；超过会被 GitHub 直接拒收
5. **分批提交**：你的改动和它的改动分开提交，回退时不必整锅端
6. **推送后验证**：远端提交号是否更新、线上页面是否真的换成新版（不是缓存）

## 三、绝对不要做的三件事

1. **不要用网页上"Add files via upload"上传**
   2026-10-23 那次就是网页传的，结果网站上的历史和本地的历史对不上，
   这次接回来费了不少事。以后一律用 `git`。
2. **不要一边改一边让它传**
   传到一半你又保存了一次，传上去的是哪个版本就说不清了。
3. **不要把视频塞进仓库**
   `video/` 有 573 MB，且 GitHub 单文件上限 100 MB。线上播放走 `database.html`
   里的 `VIDEO_URLS` 外链。

## 四、出问题时先看这个

| 现象 | 多半是什么 | 怎么办 |
| --- | --- | --- |
| `Connection was reset` | 加速工具没开 | 打开 Steam++ 再来 |
| `rejected / non-fast-forward` | 网站上又有新东西 | 先 `git fetch origin` 再 `git rebase origin/main`，别强推 |
| `could not read Username` | 登录凭据没存 | 推送时按提示登录一次，或粘贴一次性令牌 |
| 推上去了但线上还是旧的 | 缓存 | 等 2 分钟，`Ctrl+F5`；或看仓库 Actions 那条是否变绿 |
| 图片/样式没变 | 同上，或文件名大小写不对 | Windows 不分大小写、网站服务器分，重命名时全小写最稳 |
