## 一、总体命题

**「一脉古道，六枚花」** —— 主页的六条主题 = 六朵八角花。

## 二、外框几何（可复算，勿手调；已逐像素核对）

```
圆心 (80,80)，外半径 R = 64，8 个顶点每 45° 一个（正上方起）
顶点 n = (80 + 64·sin(45n°), 80 − 64·cos(45n°))
连接顺序：0→3→6→1→4→7→2→5→0   （星形多边形 {8/3}，跨度 135°）

每条边 = 一段内凹圆弧，做法（三步，全部显式几何）：
  ① 顶点连线，弦长 c = 2R·sin67.5° = 118.26
  ② 弦中点沿「垂直弦、背离画布中心」的方向压 BULGE·c = 0.25×118.26 ≈ 29.6 → 得边中点
  ③ 过「两端点 + 边中点」三点定圆 → 圆心与半径唯一确定（r ≈ 73.9）

结果：顶点半径 64、边中点半径 54.06（凹口深 10，约 15%）
```

**三个坑（本轮都踩过，务必不要重犯）**

1. **不能用「弧半径」当参数。** 半径 ∝ 弦长，直接照 320 画布那版等比缩小取 r=6.2，弦长会远超直径，圆心跑到弦中点附近，整朵花塌成一团乱线。
2. **凹的方向必须垂直于弦，不能朝画布中心。** 跳 3 位的边几乎穿过圆心（弦中点离中心只有 24.49），朝圆心压等于顺着弦滑回去。
3. **不要靠 SVG 的 `large-arc` / `sweep` 标志位去猜。** 手推极易把方向搞反，同一个 `A` 命令写出来是另一个方向的弧。用 `images/图案/check_frame_fit.py` 的解析采样核对。

对称铁律（引自 `八角花凹边原理演示`）：只要 8 个顶点共圆、等角分布、8 条边凹同样多，**必然对称**；手调单个顶点必破对称。

**核对记录**：`python images/图案/build.py` 生成 → `python images/图案/check_frame_fit.py` 自检（外框顶点/边中点半径 + 七枚内芯是否全部落在框内）；
再用 headless Chrome 截图逐像素量：顶点半径 64.5、边中点半径 55.7~56.0（含 2.2 描边宽度），与设计值一致。

## 四、主页改动

### 1. 丝状摆动装饰（跑马灯下方）

跑马灯是一条横着走的带，它下面挂一排 **22 根丝缕**：丝缕顶端钉死在带子的底边上，
跟着带子一起走；下端自由，滚轮一动就往后甩、然后摆回来。

**「顶端钉住」是这一条的验收标准**，靠两件事实现：

1. 变换原点落在顶端（`transform-origin:50% 0`，丝缕的 knot 正好在带子底边）；
   摆角 Ω 只改变下端的倾斜，顶端不会横向离位。
   实测：把摆角从 0° 拨到 ±18°，顶端位置只移动 **1.1px**（那 1px 是菱形 knot 自身的
   包围盒在旋转时变宽，不是离位）。
2. 物理用**强迫摆**，不用「滞后跟随」。支点（带子）以加速度 a 运动时：
   `L·Ω″ = −g·sinΩ − a·cosΩ − c·Ω′`。

**一个已修正的错误做法（记下来，别再犯）**：最初用「滚轮速度 → 目标摆角，
丝缕慢慢追上去」的滞后模型。它的角位移是靠 `Ω/ω` 反推的，等于让顶端跟着滞后量漂移，
**顶端会跟带子脱开**——这正是被指出的问题。强迫摆没有这个毛病。

**驱动方式**：滚轮的每一格是**速度的阶跃**，作用在悬挂物上就是一次角冲量。
不能拿加速度当持续力——一格的加速度高达两万 px/s²，丝缕会被瞬间打到限位
（这也解释了「只动一点点」与「贴着限位不动」两种症状同源）。

```
railVel = 180ms 窗口内累加的滚轮速度(px/s)，上限 2400
dOmega  = −sign(dy) · |dy|·60/1000 · (TAS_DRIVE/100)     每次滚动事件注入
Ω″      = −k·sinΩ − 0.42·Ω − c·Ω′ + 极缓气流              k = g/L，L 取 95px
s″      = −16(s−1) − 3.2 s′ + |railVel|·6e-6·gain         竖向微伸展
```

- 每根丝缕各有自己的 **摆长 k（±15%）、阻尼 c（±15%）、敏感度 gain（0.72~1.28）**，
  实测同一时刻角离散度 3~11°
- 积分用**半隐式欧拉 + 1/90s 固定子步**；显式欧拉在这套刚度下会数值发散
- 摆角钳在 **±18°**，并带**抗积分饱和**（贴到限位就不再灌冲量，否则连续滚动会把它钉住）
- 顶端随带子移动：实测上下 4px（跟着带子走），横向 1px（钉住）

**实测标定**（headless Chrome + CDP 合成滚轮，丝缕全程留在视野内）：

| 阶段 | 平均摆角（度） |
| --- | --- |
| 滚动中 | −7.6 → −15.5 → −12.5 → −3.2 → +6.0 → +6.9 → +3.0 → +4.4 → −1.8 → −8.4（来回穿零，确实在荡） |
| 停手后 | 5.2 → 9.3 → 9.0 → 7.2 → 4.5 → 2.2 → −0.6 → −2.7 → −4.3 → −3.9 → −3.1 → −1.8 → −0.5 → +0.7（阻尼回零） |

峰值 ±18°，贴限位最多 2 根（正常滚动时为 0）。

**尺寸**：容器高 **124px**（原为 236px），单根丝缕 **90~99px**，为容器的 82% 以内；
窄屏 96px。顶部那条针脚线（`.tassel .rail`）就是「带子底边」，丝缕挂在它下面。

**省电与无障碍**：整段滚出视野时物理暂停（IntersectionObserver），切标签页也暂停；
`prefers-reduced-motion: reduce` 时不跑物理，交给 CSS 那份极轻的摆动。

## 五、六个主题页（`themes/`）

`python themes/gen_themes.py` 生成。一份版式 + 六份内容 → 六个自包含 HTML：
**版式改动一次到位，不会六页走样**。`theme.css` 被内联进每个页面（本地双击独立可看，
不依赖别处文件），只有 `assets/motifs.js` 外链。

### 文案口径（重要）

本栏目面向公众与研究者，**不是设计作品说明书**。正文只写「这是什么、有什么依据、
能查到什么」，每页四节：

```
Ⅰ 概况 / 是什么      —— 定义、性质、名录级别
Ⅱ 历史脉络 / 唱法 / 形制 —— 来龙去脉、仪式过程、构造特征
Ⅲ 记录与现状        —— 保护状况、相关实物与图片、需注意的事项
Ⅳ 资料来源          —— 分级引用（A 官方 / B 学术 / C 权威媒体 / D 公众）
```

**禁止出现在页面上的说法**（已在生成器中全文清理，可用下列词做回归自检）：
`毕设` `本站` `本页` `转译` `辨识焦点` `纹样怎么来的` `设计说明` `纹样系统`
`同一家族` `破格` `外框固定` `内芯换主题`。

存疑事项用 `⚠` 标在对应小节，按「据传／一说」并置，不下定论。

每页结构一致（家族感）但**纹样 / 动效 / 版式各异**（各自身份）：

```
顶栏（≤ 返回主站 · 站名 · 序号/主题名）
首屏：纹样主视觉（大号八角花 + 该主题核心符号动效）+ 竖排题名 + 副题 + 级别出处
Ⅰ 它是什么     —— 严谨数据，逐条标出处
Ⅱ 纹样怎么来的 —— 核心符号 → 几何构形（画出构造过程）+ 一字排开的变体
Ⅲ 视觉转化     —— 纹样在页面/实物上的用法（示例卡）
Ⅳ 来源         —— 分级引用（A 官方 / B 学术 / C 权威媒体）
页脚：共用的六主题 + 支线轮换导航 + 回主站
```

字体、配色、页脚与主站一致；每页在无 JS 时仍可读（动效为渐进增强）。

### 2. 版式

只加一条规则（写在 `theme-experience.css` 的 HERO 段内）：

```css
.hero-art .hero-pattern{display:block;width:100%;height:auto}
```

- 桌面 `.hero-art` 宽 `min(100%,560px)` → 图案 **560×560**；≤900px 随 `.hero-art` 缩到约 270×270
- **不加第二道框**：图案自带边框（八角连弧 / 回纹 / 十字带），再包一层就成了双层框
- **不加滤镜**：这是色彩稿，压饱和或改对比就失去意义（`field-media` 那套滤镜是给照片用的）
- 首屏是 1:1 方图，宽高属性已声明，不会抖版式；也不写 `aspect-ratio`，将来换非方图不会被压扁

### 3. 图片

`A毕设图形/六主题图案/*.png` 是 5000×5000 全不透明平涂插画，不能直接上站。转成：

```
assets/theme-pattern/{key}-1400.webp   约 250–406 KB
assets/theme-pattern/{key}-700.webp    约 120–192 KB
```

- **用无损 WebP**：平涂 + 硬边 + 大量细线，有损模式会在细线周围振铃；
  实测无损比 q92 更小或相当（风雨桥 283K vs 286K），且逐像素与原图一致。
- `srcset` + `sizes="(max-width:900px) 58vw, 560px"`：1 倍屏取 700w（560 槽位够用），
  2 倍屏自动取 1400w（已实测）；首屏图不 lazy，`decoding="async"` + 声明 `width/height`。
- 12 个文件合计 2.69 MB，**每个专题页只加载自己那一张**。

### 4. 怎么改、怎么重跑

```bash
python themes/scripts/apply_hero_pattern.py
```

幂等：已经是图案就跳过；若页面里还残留旧版「图案」段，会顺带整段撤掉。
文案（`alt`）在脚本顶部 `DATA` 里改，别手改六份 HTML。

⚠ **与 `gen_themes.py` 的顺序**：重跑 `gen_themes.py` 会把首屏写回线稿纹样，
重跑后必须再执行一次 `apply_hero_pattern.py`。
