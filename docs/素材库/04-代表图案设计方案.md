# 04 · 代表图案设计方案(潇贺古道 · 贺州)

> 配套文件:`图案/` 目录下 7 个分层 SVG(14KB,可直接打开/导入 AE/转 Lottie)。
> 目标:从真实文化遗产中提炼**可识别、可简化、可动起来**的代表图案。

---

## 一、简化设计五原则(先读这个)

1. **一个图案一个记忆点**:风雨桥记"双拱+飞檐",女书记"菱形",炸龙记"角+火花"——只留 1~2 个最强特征,其余全部删。
2. **几何化三件套**:直线、圆弧、正圆角。所有曲线尽量用 `q`/`a` 弧线(本套图案全部如此),转矢量/导入 AE 零失真。
3. **两级对比**:主体用 4~5px 粗线,细节用 2~3px 细线;颜色上"一主一辅"(群青 + 朱砂点缀)。
4. **负空间留白**:每个图案都在留白中"呼吸",裁剪成圆形/菱形/扇形都成立。
5. **分层即动效**:每个 SVG 已按 `id` 分组(如 `water`、`wing-l`、`sparks`),**哪一层要动,直接改那一层**——这是为动态化预留的骨架。

## 三、主视觉组合建议(毕设封面/主视觉用)

**方案 A(推荐)**:风雨桥为主体,桥下接潇贺古道曲线(7 号图案的线),桥檐下挂女书菱形与蝴蝶——"桥承载路,路串联人"。
**方案 B**:盘王印八角做外环,中心放女书菱形,环内嵌风雨桥剪影——徽章感,适合 Logo/印章。
**方案 C**:古道线从左下到右上贯穿,6 个节点换成 6 个主题小图标(桥/字/蝶/印/鼓/龙)——信息图叙事线,适合时间轴。

## 四、配色体系(瑶族"五色" × 中国色)

主色系(本套 SVG 已用):
- **群青深** `#2F4B6B` — 主色(水/路/墨)
- **朱砂** `#C3272B` — 点缀色(火/印章/鼓点/灯笼)
- **宣纸白** `#F7F3EA` — 底(材质感)

瑶族五色扩展(来自 ihchina 学术文《贺州瑶族服饰纹样与设计转化》):
- 黑 `#26241F`(底)、红 `#B23A2E`、黄 `#D9A441`、白(底)、蓝 `#2E5A88`
- 用法:正文用"群青+朱砂"两色;节日/庆典版面换"黑底+朱砂+黄"三色;H5 动态版可把黄做高亮强调色。

## 五、动效技术路线(三档,由易到难)

| 档位 | 技术 | 适合 | 成本 |
|---|---|---|---|
| ① 零代码 | SVG 内嵌 CSS `<style>`(本套文件已分层,加 animation 即可) | 网站 H5、PPT 插入 | 最低,改 5 行 |
| ② 标准 | SVG SMIL(`animate`/`animateTransform`/`animateMotion`) | 路径流动、旋转、描线 | 低,语法固定 |
| ③ 专业 | 导出到 AE → **Lottie**(bodymovin) | 毕设动态海报/视频/App | 需 AE,效果最灵活 |

**推荐流程**:本套 SVG → AI 转矢量(或直接用)→ 按 `id` 分层导入 AE → 加 6 个标准动效 → Lottie 导出 → 网页/视频双用。

## 六、动效配方速查(直接照抄参数)

| 动效 | 作用层 | 参数 |
|---|---|---|
| 水流 | `#water` | `translateX` 平移 40px 往返,8s 线性 infinite |
| 蝴蝶扇翅 | `#wing-l`/`#wing-r` | `rotate` 以(160,150)为原点 ±8°,3s ease-in-out infinite alternate |
| 鼓点弹跳 | `#beat-1~4` | `translateY` -14px,0.9s/1.1s/1.3s/1.5s 各自循环(stagger) |
| 火花闪烁 | `#sparks circle` | `opacity` 0.3↔1,0.4~0.8s 不同 delay |
| 火珠呼吸 | `#fire-pearl` | `r` 8↔12,2s ease-in-out infinite |
| 印纹旋转 | `#spokes` | `rotate` 360°,60s linear infinite |
| 线路流动 | `#route` 上叠加亮点 | SMIL `animateMotion` 沿 `#route-path`,8s |
| 女书浮现 | `#dots polygon` | `opacity` 逐个 0→1,0.3s 步进,循环 |
| 描线生长 | `#main-char` | `stroke-dashoffset` 动画,2.5s 一次 |
| 风雨桥檐角 | `#lanterns` | `opacity` 呼吸 3s |
